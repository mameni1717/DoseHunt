# Multi-pays : conventions du code web

## Pays
- `lib/country.ts` : table `COUNTRIES` (FR à la racine, ES sous `/es`), `countryFromPath(segment)`, `href(country, path)`.
- Toutes les pages sont sous `app/[country]/`. Dans une page : `const country = countryFromPath((await params).country); if (!country) notFound();`
- Le pays voyage explicitement : composants serveur → prop `country: Country` ; fonctions de `lib/data.ts` → premier argument.
- Interdit : `currentCountry()`, une constante de pays au niveau d'un module, un lien interne écrit en dur.
  Tous les liens internes, `action` de formulaires, `redirect()` et canoniques passent par `href(country, "/chemin")`.
  Les liens relatifs de requête (`qs(base, {...})` → `?sub=…`) restent valables tels quels.
- Clés de stockage navigateur par pays : `dosehunt-compare-<ISO>`, `dosehunt.optimiser.v1.<ISO>`.
- API (`/api/...`) : le pays arrive explicitement (champ `country` du corps JSON ou paramètre `?country=`), validé avec `countryByIso()` ; défaut FR.

## Textes
- Fichiers : `messages/fr/<espace>.ts` (référence) et `messages/es/<espace>.ts` (mêmes clés, `Record<keyof typeof fr, string>`).
  Clés préfixées par l'espace : `offer.inStock`, `product.title`…
- Les textes français sont copiés SANS changer un mot (la France doit rester identique au caractère près,
  espaces insécables et apostrophes compris).
- Serveur : `t(lang, "clé", { var })`, pluriel `tp(lang, "clé", n)` avec `clé.one` / `clé.other` (variable `{n}`),
  texte avec balises : `rich(lang, "clé", { link: (c) => <Link …>{c}</Link> })` et `<link>…</link>` dans le texte.
- Composants client (`"use client"`) : n'importent PAS `lib/i18n` (cela enverrait toutes les langues au navigateur) ;
  le composant serveur parent leur passe les textes déjà traduits dans une prop `m` (objet de chaînes).
- Libellés des catégories : `categories(country)`, `categoryById(country)[id]`, `modeDef(country, cat, mode)`,
  `activeLabel(country, …)`, `milkOrigin(country, code)`, `vitaminsGroup(country)` (`lib/categories.ts`).
  `SPEC_BY_ID` / `CATEGORY_IDS` pour valider un identifiant sans texte.
- Formats : `formatMoney(n, country)`, `formatNumber(n, country, décimales)`, `formatDate(d, country)`, `ago(d, country)`,
  `monthYear(country)` (`lib/format.ts`, `lib/site.ts`). Plus de `eur()`, `num()`, `dateFr()`, `toLocaleString("fr-FR")`.
- Espagnol : naturel, tutoiement (« tú »), ton direct comme en français ; termes que les Espagnols tapent
  (« proteína whey », « creatina monohidrato », « pre-entreno », « barritas de proteína », « código descuento »,
  « envío gratis ») ; jamais de mot à mot. Noms de produits et extraits de fiches : tels quels.
- Tests : `npm test` (complétude des traductions, requêtes filtrées par pays), `npx tsc --noEmit`.
